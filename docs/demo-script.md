# 3-minute demo script

**Live-first (if the scan works):** 0:00 *Integration → Connect & diagnose Amplience* (real hub, repositories, locales) → Overview → *Scan Amplience* (progress bar); point at the `LIVE · Amplience` badge, scan time, coverage. 0:45 Localization → open a real finding (e.g. an English-only blog post); use the ↗ to open the content item in Dynamic Content. 1:15 Tick consent → *Generate proposal with OpenAI* → show model, effort, tokens, validation → edit a phrase → *Approve*. 2:15 "Approval is not a CMS write" (audit trail, write conditions listed). 2:30 *Reference graph*: click the most-linked author or image item, show the blast radius, then architecture and roadmap.

**Offline fallback:** 0:00 Switch to DEMO; KPIs and the sample-data banner. 0:30 Localization → click Italy / Campaign cell, status *Missing* → critical campaign field. 1:00 *Generate simulated proposal* → edit → *Approve*. 2:00 *Apply to demo dataset*. 2:30 KPIs recalculate; *Reset demo*; Reference graph (blast radius + the deliberate broken link).
