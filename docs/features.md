# Features

| Page | What it does |
|---|---|
| **Overview** | Health score, coverage, release blockers, pending approvals, per-locale coverage, priority queue, real scan-history trend (live) |
| **Localization** | Locale × content-type coverage matrix, filterable/sortable issue queue, CSV export, bulk dry-run, **review drawer** (source / existing / editable AI proposal, validation, audit trail) |
| **Content health** | Transparent rule list, score breakdown with the exact formula, severity/rule filters, evidence and remediation |
| **SEO & AI audit** | 16 transparent rules across SEO and AI discoverability, schema-derived scoring (delivery keys as URLs, markdown bodies, linked text and image items), findings workspace, human-reviewed AI suggestions for meta text. See [SEO audit](seo-audit.md) |
| **Schema governance** | Complexity and change-risk per content type, real field usage, structural-overlap heatmap, 11 rules with recommendations. See [Schema governance](schema-governance.md) |
| **Reference graph** | Interactive force graph of content items and assets: **blast radius** before an edit, dependencies, hubs, broken links, orphans |
| **Insights** | Issues by market, coverage by type, AI operations (acceptance rate, cost), clearly-marked future GA4/commerce stub |
| **Roadmap** | The 10 product modules with native-overlap notes and prototype boundaries |
| **Integration** | Connect & diagnose Amplience, check OpenAI model access, write-safety and policy status |

Live mode shows `LIVE · Amplience`, demo mode shows `DEMO · Sample fixtures`; every page states which one you are looking at, the hub, the repositories and the scan time. Live items deep-link into the Dynamic Content app.
